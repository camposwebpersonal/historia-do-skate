# História do Skate

Experiência editorial responsiva sobre a evolução do skate, das origens na
Califórnia à estreia olímpica e à força da cena brasileira.

## Desenvolvimento local

Abra `index.html` em um servidor HTTP local:

```bash
python3 -m http.server 8080
```

O projeto usa HTML, CSS e JavaScript sem dependências de compilação.

## Fotografia

O banner usa uma fotografia real de Allan Mas, disponibilizada gratuitamente
pelo Pexels. Consulte [ASSET-LICENSES.md](ASSET-LICENSES.md) para a origem e a
licença. A arte anterior está preservada em `assets/BKP/`.
